# Workshop Assembly asset provenance

The original generated WebP workshop states were retired on 2026-08-18 after visual review. No generated workshop raster imagery remains in the project or renders on the site.

The current Access → Build → Lead sequence is a real-time WebGL scene built from Three.js geometry and physically based materials. Its case, chassis, wheels, board, battery, and sensors remain separate meshes so scroll position can assemble the rover continuously instead of crossfading between images.
